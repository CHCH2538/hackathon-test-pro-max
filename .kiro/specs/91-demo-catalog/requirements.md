### Data model และแหล่งข้อมูล

- **D-11** ขั้นตอนและเอกสาร: คู่มือประชาชนตาม พ.ร.บ.การอำนวยความสะดวกฯ (ทุกหน่วยงานต้องเผยแพร่), เว็บไซต์หน่วยงาน → เก็บเป็น RAG + ตารางที่คนตรวจแล้ว
- **D-12** พิกัดสำนักงาน: เว็บไซต์กทม. / กรมการขนส่งทางบก / บช.น., Longdo Map POI
- **D-13** เขตปกครอง: ชั้นข้อมูลเขตกทม. บน [data.go.th](https://gdcc.data.go.th/en/dataset/wms)
- **D-14** เขตรับผิดชอบ สน. ทั้งหมดใน กทม.: ยังไม่พบชุดข้อมูล polygon สาธารณะ (ดูคำถามเปิด) → MVP ใช้แขวงเป็นตัวแทน + ให้ผู้ใช้ยืนยันทางโทรศัพท์
- **D-15** วันหยุดราชการ: ประกาศคณะรัฐมนตรีรายปี

### Architecture, MVP และ KPI

- **M-02** 5 บริการที่ตรวจข้อมูลครบ: แจ้งความทรัพย์สินหาย/ถูกขโมย, ถูกหลอกโอนเงินออนไลน์, ต่อใบขับขี่, ทำบัตรประชาชนใหม่, ย้ายที่อยู่
- **M-04** Jurisdiction: polygon สน. นำร่อง 5–10 แห่งที่ใช้ใน demo
